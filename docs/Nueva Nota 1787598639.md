#### orientaciones y aprendizajes derivadas de trabajo con open code a analizar 


**Resumen Ejecutivo**
Open Code es una alternativa de código abierto y CLI a Claude Code. Permite utilizar modelos gratuitos (por defecto) o conectar APIs comerciales (OpenAI, Anthropic, Gemini, modelos locales/chinos) para optimizar costos y flujos de desarrollo asistido por IA.

---

**Pilares del Ecosistema Open Code**

* **Comandos (`/`):** Definen **qué hacer** (acciones repetibles, flujos de prompting, navegación de historial).
* **Skills:** Directorios o paquetes de **conocimiento/estándares** (buenas prácticas de frameworks, DBs, scripts CLI).
* **Agentes:** Definen **quién lo hace** (roles de ejecución y análisis).
* **MCP (Model Context Protocol):** Conexión con **herramientas externas** y automatizaciones (e.g., testing E2E con TestSprite).

---

**Estructura de Agentes y Roles**

* **Agentes Primarios (Ciclo con `Tab`):**
* `plan`: Solo lectura. Diseña la estrategia sin modificar archivos.
* `build`: Agente ejecutor. Aplica cambios y escribe código.
* *Personalizados:* Creados vía CLI (`opencode agent create`) o archivos `.md`.


* **Subagentes (Invocación con `@`):**
* `general`: Propósito general con acceso de escritura.
* `explore`: Solo lectura; optimizado para búsquedas e indexación del codebase.
* *Especialistas:* Auditores de seguridad, documentalistas o DB admins invocados manual o automáticamente por el agente primario.



---

**Orientaciones y Recomendaciones (Mejores Prácticas)**

* **Estrategia Plan-Then-Build:** Planificar siempre en modo `plan` antes de pasar a `build` para ahorrar tokens y prevenir código roto.
* **Uso de `AGENTS.md`:** Generarlo al inicio (`/init`) para documentar el stack, comandos y reglas de orquestación de subagentes.
* **Control de Tokens:** Activar el visor de costos/tokens integrado y ajustar variantes de razonamiento (`Ctrl + T`) según la complejidad de la tarea.
* **Manejo de Contexto:** Probar comandos, skills y agentes primero a nivel de proyecto (`.opencode/`) antes de promoverlos al entorno global.
* **Reinicio de Sesión:** Reiniciar la CLI tras agregar o modificar MCPs, skills o comandos para recargar el contexto.
* **Rollback Inmediato:** Usar el menú contextual del chat para revertir cambios ante errores en lugar de encadenar prompts de corrección.

---

**Qué NO Hacer (Anti-Patrones)**

* **No sobrecargar `AGENTS.md`:** Evitar incluir documentación genérica innecesaria o tecnologías marginales que desvíen al LLM del código real.
* **No encadenar fixes iterativos:** Si el modelo genera un error destructivo, no intentar arreglarlo con prompts sucesivos; hacer *rollback* inmediato y redefinir el plan.
* **No dejar subagentes sin alcances definidos:** No otorgar permisos de escritura o ejecución a subagentes que solo requieran análisis o exploración.
* **No hardcodear credenciales en MCPs:** Evitar exponer claves directamente en configuraciones públicas; estructurar las variables de entorno en el bloque `environment` de `opencode.json`.

---

**Comparativa de Herramientas y Componentes Clave**

| Herramienta / Función | Propósito Principal | Integración / Acceso |
| --- | --- | --- |
| **Open Code CLI** | Entorno de desarrollo y ejecución de agentes | `npm i -g opencode-ai` (o binario directo) |
| **Open Code Zen** | Enrutador curado de modelos optimizados para código | Suscripción / API key dedicada en `/connect` |
| **Skills (`skills.sh`)** | Inyección de estándares de la industria (Vercel, Supabase) | Directorio `.agents/skills` o `.opencode/skills` |
| **MCP TestSprite** | Generación y ejecución de tests E2E automatizados con video | Configuración en `opencode.json` bajo bloque `mcp` |

---

**Comandos y Atajos Principales de la CLI**

* `Tab`: Alternar entre agentes primarios (`plan`, `build`, etc.).
* `@`: Invocar subagentes especializados (`@explore`, `@security-auditor`).
* `/`: Desplegar menú de comandos del sistema y personalizados.
* `Ctrl + T`: Cambiar variantes de esfuerzo de razonamiento del modelo.
* `/timeline`: Navegar y restaurar puntos anteriores del historial del chat.
* `/session`: Listar, reanudar o bifurcar sesiones previas.
